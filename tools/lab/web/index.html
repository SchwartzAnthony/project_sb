What this runs

This page runs the game's own rules code (AbilityEngine, the tier ladder, Emblems, ShotOdds) compiled for the browser, reading the same data/*.csv files. It is built by tools/lab/build.sh from the branch and commit shown at the top.

A round is played the way tests/sim_runner.gd plays it: passives, four duels with abilities resolved on the stack, the bank, then the shot against the keeper. Left out, because they only exist on the pitch: touches, mines being worked, gravestones, fouls and free kicks, and the Emblem race (so no Ultimates turn on). Questions a card would ask are answered with their default and listed in the log.

Adventure opens the real AdventureEncounter with no pitch, the way tools/adventure_soak.gd does, with the clock run fast. Stamina, knock-outs and the tier rotation carry from wave to wave, and stand-ins go home after each fight. Items and fleeing are left out. The one-off breakpoints in "Many runs" are counted from the fight log.

In the match, two things differ from the simulator, to match the real match: a token that takes a card's place is offered in the draft instead of the card, and the keeper's stamina is handed to the engine before each round.
